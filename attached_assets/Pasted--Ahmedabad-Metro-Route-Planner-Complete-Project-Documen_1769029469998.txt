🚇 Ahmedabad Metro Route Planner - Complete Project Documentation
Project Overview
A Progressive Web App (PWA) for navigating the Ahmedabad Metro system. It provides real-time train tracking, intelligent route planning, fare calculation, and social features like journey sharing.

Live URL: https://ahmedabadmetro.lovable.app

🛠 Technology Stack
Layer	Technology
Framework	React 18 + TypeScript
Build Tool	Vite + PWA Plugin
Styling	Tailwind CSS + shadcn/ui
Mapping	Leaflet.js
State	React Context + useState/useCallback
Routing	React Router v6
Data Fetching	TanStack React Query

  direction: 'forward' | 'backward';
  startTime: string;           // "HH:MM"
  stations: string[];          // Station IDs in order

}
🧭 Route Planning Algorithm (src/lib/routePlanner.ts)
Core Functions
Function	Purpose
planRoute(origin, dest)	Find best route for current time
planRouteWithDeparture(origin, dest, depMins)	Route for specific departure
findShortestPath(origin, dest)	BFS for minimum interchanges
getAvailableDepartures(origin, dest)	All departure options
findCommonTrainRoute(segments, origin, dest)	Coordinate with friend
calculateJourneyProgress(route, currentMins)	Live journey tracking
Route Step Types

type RouteStep = {
  type: 'board' | 'interchange' | 'travel' | 'alight' | 'bus';
  station: Station;
  line?: 'blue' | 'red' | 'green' | 'purple';
  trainTime?: string;
  trainId?: string;
  waitTime?: number;
  stationCount?: number;
  // ...
}
Algorithm Flow
Direct Route Check - Can a single train reach destination?
BFS Pathfinding - Find minimum interchange path
Time-Aware Scheduling - Find actual train times
Fare Calculation - Use matrices or distance formula

📊 Data Flow
User selects origin/destination
          ↓
planRoute() or planRouteWithDeparture()
          ↓
findShortestPath() → BFS across lines
          ↓
buildTimeAwareRoute() → Match with train schedules
          ↓
calculateFare() → Lookup fare matrices
          ↓
PlannedRoute object returned
          ↓
RoutePlanner renders steps
MetroMap draws route visualization
