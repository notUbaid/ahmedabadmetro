# Ahmedabad Metro Route Planner

A real-time Ahmedabad Metro route planner application.

## Project info

This project is a Progressive Web App (PWA) built to help users navigate the Ahmedabad Metro system.

## Technologies

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Leaflet (for maps)

## Development

To start the development server:

```sh
npm install
npm run dev
```

## Build

To build for production:

```sh
npm run build
```
